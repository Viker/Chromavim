# Chromavim

Chromavim is a Visual Studio Code extension that changes the color of your Razer Chroma devices based on your VsCodeVim mode. This provides a visual indicator of your current Vim mode through your Razer peripherals.

## Features

This extension integrates VSCodeVim with Razer Chroma devices to:
- Change your Razer device colors based on the current Vim mode (Normal, Insert, Visual)
- Provide visual feedback through your Razer peripherals
- Enhance your Vim workflow with hardware indicators

## Requirements

- Visual Studio Code 1.20.0 or higher
- VsCodeVim extension
- Razer Synapse 3 with Chroma Connect enabled
- One or more Razer Chroma-enabled devices

## Commands

This extension contributes the following commands:

* `extension.vschroma.startAnimation`: Start the Chroma animation
* `extension.vschroma.stopAnimation`: Stop the Chroma animation
